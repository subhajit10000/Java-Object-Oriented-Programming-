 Object-Oriented Programming (OOP)
-----------------------------------
Object-Oriented Programming (OOP) is a programming approach that organizes software around objects and classes rather than focusing only on functions and procedures. It helps developers build applications that are modular, reusable, maintainable, and easier to understand.

The four main principles of OOP are Encapsulation, Abstraction, Inheritance, and Polymorphism. Encapsulation combines data and the methods that operate on that data within a single class while controlling access to internal details. Abstraction hides unnecessary implementation details and exposes only the essential functionality. Inheritance allows a class to acquire properties and methods from another class, reducing code duplication. Polymorphism allows the same method or interface to behave differently depending on the object using it.

A class acts as a blueprint for creating objects, while an object represents a specific instance of that class. OOP is widely used in languages such as JavaScript, Java, Python, C++, and C#.

OOP provides several advantages, including code reusability, scalability, easier debugging, improved organization, and simpler maintenance. It is especially useful for developing large applications where different components need to interact with each other.

This repository demonstrates fundamental OOP concepts through practical examples, including classes, objects, constructors, methods, inheritance, encapsulation, abstraction, and polymorphism.
